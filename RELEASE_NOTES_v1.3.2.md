# UV–Vis Spectral Studio v1.3.2

- Reject explicit wavelength units and signal types that cannot be interpreted as nm and absorbance A, including during manual column mapping.
- Distinguish measured, processed, interpolated and synthetic values in numerical outputs. Invalidate lookup and measurement results when their inputs change.
- Adapt X-axis ticks to narrow derivative views. Regression checks preserve the D0 SVG byte for byte across five representative settings.
- Run large derivative plot calculations in a cancellable background worker. Enforce session limits before accepting new curves and serialize file imports and project restores.
- Provide Arabic measurement and fitting-window reports.

Download **UVVisSpectralStudio-v1.3.2.html** from the release assets and open it in a modern browser to use the app offline. The release includes the tagged source and is licensed under Apache-2.0.
